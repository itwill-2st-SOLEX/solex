# MES·ERP 신발 제조 공장 시스템
아이티윌 부산교육센터 Spring Boot & AWS 클라우드 기반 백엔드 실무 프로젝트 부트캠프에서 진행한 팀 프로젝트입니다. 신발 제조 공정을 관리하는 MES(생산관리시스템)와 ERP 기능을 결합한 시스템입니다.

🏆 Spring Boot & AWS 기반 팀 프로젝트 경진대회 부문 최우수상 수상 (2025.07, 아이티윌 부산교육센터)

## 프로젝트 개요
- 개발 기간: [2025.05 ~ 2025.07]
- 팀 구성: [7명]
- 주요 내용: 신발 제조 공정 흐름 관리(MES)와 전자결재, ERP 기능을 포함한 시스템

## 담당 역할 (팀장)
**[ERP]**
전자결재 모듈을 담당했습니다.
- 기안서 유형에 따라 결재자가 자동으로 지정되는 로직 설계 및 구현
- 문서 종류별로 결재 담당자가 자동 매칭되는 구조 설계

**[MES]**
- 작업지시 등록/조회 기능 구현
- 창고 배정 기능 구현
- 대시보드 구현
- 사내 메신저 기능 구현

## 기술 스택
`Java` `Spring` `MyBatis` `MySQL` `AWS`

## 배운 점
MES는 생소한 도메인이라 팀원들과 매일 남아서 용어와 공정 흐름을 함께 정의하며 기반을 다졌습니다. 이전 ERP 프로젝트(급여 파트)와 비교해 더 복잡한 업무 흐름을 시스템으로 구현하며 한 단계 성장했습니다.
